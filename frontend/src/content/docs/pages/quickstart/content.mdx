## What do you need before you start?

- A Vyostra AI account on the Starter, Growth or Agency plan. API access is not part of the free trial.
- Somewhere to run code that is not a web page: a terminal, a server or a serverless function.

## Step 1: How do you create an API key?

1. Sign in to the Vyostra AI dashboard and open **Settings**.
2. Find the **API keys** section.
3. Type a name that says what the key is for, such as `CRM sync`.
4. Leave the permissions you need ticked and click **Create key**.
5. Copy the key straight away. It starts with `vy_live_` and is shown only once.

The same section shows your **API base URL**, which is `https://vyostra.com`. Every request in these docs goes to that URL followed by a path such as `/v1/leads`.

<Callout title="Keep the key out of your code" tone="warning">
Store the key in an environment variable or a secrets manager. Anyone who has it can read your leads until you revoke it.
</Callout>

## Step 2: How do you make the first request?

Put the base URL and the key in two environment variables, then ask for your five most urgent leads.

```bash
export VYOSTRA_API_URL="https://vyostra.com"
export VYOSTRA_API_KEY="paste your vy_live_ key"

curl "$VYOSTRA_API_URL/v1/leads?limit=5" \
  -H "Authorization: Bearer $VYOSTRA_API_KEY"
```

The same request in Node.js 18 or later:

```js
const response = await fetch(`${process.env.VYOSTRA_API_URL}/v1/leads?limit=5`, {
  headers: { Authorization: `Bearer ${process.env.VYOSTRA_API_KEY}` },
})

if (!response.ok) {
  const { error } = await response.json()
  throw new Error(`${response.status} ${error.code}: ${error.message}`)
}

const page = await response.json()
console.log(page.total, 'leads in total')
console.log(page.data)
```

And in Python:

```python
import os
import requests

response = requests.get(
    f"{os.environ['VYOSTRA_API_URL']}/v1/leads",
    params={"limit": 5},
    headers={"Authorization": f"Bearer {os.environ['VYOSTRA_API_KEY']}"},
    timeout=30,
)
response.raise_for_status()

page = response.json()
print(page["total"], "leads in total")
print(page["data"])
```
